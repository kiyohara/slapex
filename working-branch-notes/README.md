# Working Branch Notes

`working-branch-notes/` は、ブランチ単位の作業目的、状況、判断、引き継ぎメモを置くためのディレクトリです。

このディレクトリの note は、最終仕様書ではなく **作業メモ** として扱います。詳細なルールは下記の共通正本を参照してください(本 README はそれらへの navigation pointer です)。

## 共通正本

- 取り扱いルール(性質・整合性スコープ・ライフサイクル・メンテコスト判断・ファイル名規約・推奨構造): `doc/guidelines/working-branch-notes-handling.md`
- 情報統制ルール(秘密情報・個人情報・顧客固有情報の禁則): `doc/guidelines/working-branch-notes-security.md`

## 新しい note を作るときは

`_template.md` をコピーし、ファイル名規約に従って配置してください。詳細は `doc/guidelines/working-branch-notes-handling.md` を参照してください。
